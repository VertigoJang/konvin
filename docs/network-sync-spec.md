# Konvin v4 — 네트워크 라이브러리 스펙 (초안)

같은 네트워크에 있는 여러 컴퓨터의 Konvin 라이브러리를 서로 찾아보고
가져올 수 있게 하는 기능. 서버와 계정 없이, 두 컴퓨터가 같은 네트워크에
동시에 켜져 있을 때만 동작한다.

## 목표 / 비목표

- 목표: 같은 네트워크의 다른 PC가 가진 영상을 찾아보고 수동으로 가져오기
- 목표: 서버 비용 없이 순수 P2P 로 동작
- 목표: 기존 UI 를 크게 바꾸지 않기 (상단 탭 2개 추가 수준)
- 비목표: 인터넷 너머 동기화, 서로 다른 네트워크 간 동기화
- 비목표: 아이튠즈식 자동·상시 동기화 (항상 수동 요청·승인 기반)

## UI 변경

기존 메인 창은 그대로 두고 상단에 탭 2개만 둔다.

- **내 라이브러리** — 지금까지의 다운로드·변환 화면
- **네트워크** — 발견된 다른 Konvin PC 목록 → 클릭하면 그 PC 의 영상
  목록 → 체크 후 "가져오기"

가져온 파일은 기존 다운로드 폴더에 그대로 떨어뜨린다. 별도 보관 위치를
만들지 않는다.

## 아키텍처

### 1) 발견 (Discovery)

- `zeroconf` 패키지로 `_konvin._tcp.local.` 서비스를 등록하고 탐색한다
- 광고에 싣는 정보: 기기 이름(최초 실행 시 사용자가 정함), 기기 UUID,
  HTTP 포트
- 앱이 켜져 있는 동안 계속 광고 + 탐색 (백그라운드 QThread)

### 2) 로컬 HTTP 서버

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| GET | `/videos` | 보유 영상 목록 (id, 제목, 크기, 날짜) |
| POST | `/request` | 다운로드 요청 등록 → 요청 ID 반환, 대기 상태 |
| GET | `/request/{req_id}/status` | 요청 상태 (대기/허용/거부/만료) |
| GET | `/download/{token}` | 허용된 요청의 토큰으로 파일 받기 |

파일 id 는 서버 내부 인덱스에서만 실제 경로로 바꾼다. 요청에 들어온
값을 파일 경로에 직접 쓰지 않는다 (경로 순회 방지).

### 3) 요청 · 승인 흐름

1. 요청 측이 `/request` 로 파일 id 를 보낸다 → 대기 상태로 등록
2. 응답 측 화면에 확인 창이 뜬다
   - 내용: "○○PC 가 'xxx.mp4'(320MB)를 요청했습니다"
   - 버튼: 거부 / 허용
   - 체크박스: "이 컴퓨터는 항상 허용"
     - 경고 문구를 함께 보여준다:
       "체크하면 이후 승인 없이 파일에 자동으로 접근할 수 있게 됩니다.
       신뢰하는 내 컴퓨터에만 사용하세요."
   - 30초 무응답이면 자동 거부
3. 허용되면 일회성 토큰(uuid4)을 발급하고 요청 상태를 갱신
4. 요청 측이 상태를 확인한 뒤 `/download/{token}` 으로 파일을 받는다
5. 토큰은 한 번 쓰거나 5분이 지나면 소멸

### 4) 신뢰 목록

- "항상 허용" 체크 시 요청 측 기기 UUID 를 `trusted_devices.json` 에 저장
- 이후 그 기기의 요청은 확인 창 없이 바로 토큰 발급
- 네트워크 탭에서 신뢰 목록을 보고 개별 "신뢰 해제" 가능
- 해제하면 다시 확인 창을 거친다

### 5) 알려진 한계

- mDNS 기기 이름은 위장하기 쉬워서, "항상 허용" 으로 신뢰한 기기가 매번
  진짜 그 기기인지 완전히 보장하지는 못한다. 공개키 기반 기기 인증까지
  가면 막을 수 있지만 이번 범위에서는 과하다고 보고 넘어간다
- 상대 PC 가 꺼져 있으면 그 파일에는 접근할 수 없다
- 평문 HTTP 라서 같은 네트워크의 다른 기기가 트래픽을 볼 여지가 있다
  (인터넷 노출은 아니라 우선순위 낮음, 필요하면 나중에 자체서명 TLS 검토)

## 데이터 모델

- `library.json` — 로컬 다운로드 이력 인덱스 (id, 제목, 경로, 크기, 날짜).
  지금의 폴더 스캔 방식을 이걸로 정리하면 `/videos` 응답도 단순해진다
- `trusted_devices.json` — 신뢰 기기 UUID 목록

## 구현 순서

1. 발견 프로토콜 검증 — zeroconf 로 두 PC 가 서로 찾는지 CLI 로 실험
2. 로컬 HTTP 서버 골격 — `/videos` 만 먼저, 인증 없이
3. 요청·승인·토큰 흐름 + 확인 창 UI
4. 신뢰 목록 저장·해제 UI
5. 메인 창에 "네트워크" 탭 추가
6. 에러 처리 (방화벽 차단, 응답 없음, 전송 중단)
