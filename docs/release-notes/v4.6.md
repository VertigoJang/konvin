## 한국어

### 네트워크 라이브러리

같은 네트워크에 켜져 있는 다른 컴퓨터의 Konvin 에서 변환된 영상을 가져올 수 있습니다. 서버도 계정도 쓰지 않습니다.

- 메인 창에 "내 라이브러리 / 네트워크" 탭
- 상대가 허용해야 파일이 전송됩니다
- "이 컴퓨터는 항상 허용" 과 신뢰 기기 관리
- 상대 컴퓨터를 부를 이름을 따로 지정 (내 컴퓨터에만 저장되며 상대에게 알려지지 않습니다)
- 설정에서 네트워크에 보일 내 이름 지정

### 자동 업데이트

업데이트 알림 창의 "지금 업데이트" 를 누르면 새 버전을 받아 갈아 끼우고 프로그램이 다시 켜집니다. 직접 받아서 다시 깔 필요가 없습니다.

- 진행률 표시, 받은 파일 크기 검증
- 알림 창에 이번 버전에서 바뀐 점 표시

### 그 밖에

- 앱 아이콘 교체
- 빌드 전 자동 검사 추가

리눅스는 소스에서 바로 실행합니다. README 의 설치 안내를 참고하세요.

## English

### Network library

Pull converted videos from another computer running Konvin on the same network. No server, no account.

- "My library / Network" tabs in the main window
- Nothing is sent until the other side allows it
- "Always allow this computer" and trusted device management
- Give a peer your own name for it (stored locally, never sent to them)
- Set how you appear on the network in Settings

### Automatic updates

"Update now" in the update dialog downloads the new version, swaps it in, and restarts the app. No more manual reinstalls.

- Progress display and size verification
- Release notes shown in the dialog

### Also

- New app icon
- Automatic checks before every build

On Linux, run from source — see the install notes in the README.
